# DS-A2 — Inference and Uncertainty (simulation-only project)

This project studies uncertainty in a two-sample mean difference using synthetic data. The notebook implements Welch inference, a percentile bootstrap interval, a sampling distribution, power curves, and a heavy-tailed counterexample.

## Run locally
Python 3.10+ recommended. From this directory:
```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
python -m pip install -r requirements.txt
jupyter nbconvert --to notebook --execute notebooks/DS-A2_Inference_Uncertainty.ipynb --output executed_DS-A2_Inference_Uncertainty.ipynb --ExecutePreprocessor.timeout=600
```

The notebook expects the project root as the working directory's parent because its output paths are relative to `notebooks/`. To execute via nbconvert from the root, add `--ExecutePreprocessor.cwd=notebooks` if supported by your installed nbconvert version, or open the notebook in Jupyter with `notebooks/` as the working directory. Figures and CSVs are written into `figures/` and `results/`.

## Design
- Seed: 20261014 (separate deterministic sub-seeds for scenarios)
- Alpha: 0.05, two-sided
- Baseline: n=40/group, effect=0.3, sigma=1
- Monte Carlo repetitions: 3,000 per design
- Bootstrap draws: 4,000
- Counterexample: Student-t errors with 3 degrees of freedom

All observations are synthetic; no external data are used.
